**CampusFinder – Campus Lost & Found Management System**

CampusFinder is a web-based Lost and Found Management System designed to help students easily report, search, and recover lost items within a college campus. The application provides a simple and user-friendly interface where users can report lost or found items by adding details such as item name, category, description, location, date, and an optional photo.

The system allows users to browse and search listings using filters such as item type, category, location, and date. Users can view detailed information about reported items, mark their own posts as resolved, and delete posts when required. A notification system also alerts users when a potentially matching lost or found item is reported.

The project is developed using **HTML, CSS, and JavaScript**, with **localStorage** used to maintain user data and reported items in the browser. The responsive interface is designed to provide a mobile-app-like experience while remaining a lightweight web application.
